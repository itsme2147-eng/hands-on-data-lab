This report documents my Hands-On Data Lab Implementation, in which I set up a working data analysis environment and completed practical exercises covering all six objectives. I installed Python 3.12 in a virtual environment with NumPy, Pandas, Matplotlib, Seaborn, Scikit-learn, SciPy and Jupyter, and wrote a verification script that confirms every library imports correctly and prints its version.

For the practical work I created a synthetic retail dataset of 400 customers, 40 products and 5,060 raw orders, deliberately containing real-world quality problems. Using Pandas and NumPy I practised selection, filtering, sorting, grouping, aggregation, pivot tables, merging and column transformation, plus array statistics and broadcasting, where vectorised code ran over 100 times faster than a loop.

Data cleaning followed a detect, fix and validate approach. I removed 60 duplicate orders, converted 150 text discounts such as 10% to numbers, standardised 123 dates written in a second format, repaired invalid ages and quantities, fixed text-based prices, harmonised inconsistent labels and imputed missing values with medians. Assertions confirm that the cleaning rules hold.

I then built eight visualisations with Matplotlib and Seaborn: bar, line, histogram, scatter, box, count and two heatmaps. The analysis covers descriptive statistics, skewness, correlations, a t-test and a chi-square test. Key findings: delivered orders produced INR 10.65 crore at a 25.1 percent margin, Electronics contributed 52 percent of revenue, October to December revenue was 80 percent higher than the rest of the year, and discounts reduced margin from 31.5 to 21.1 percent. A structured, reproducible notebook documents the code, outputs, charts and insights, and the full project is in my GitHub repository.
